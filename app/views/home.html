Router + Controller

FastRoute-powered router with @id:int typed params, group middleware, and DI injection.

ORM + query_gen

Active-record models with dirty tracking and dynamic SQL via %placeholder%.

Cache

Redis-first with file fallback. Posts list is cached with cache::remember() and invalidated on write.

cache::remember() cache::delete()
🔐

Session + Auth

Redis-backed sessions with flash messages, regeneration on login/logout, and auth middleware.

session::flash() auth_middleware
✅

Validation

Chainable rules engine — required|email|min_len:6 — returns typed result with per-field errors.

validate::make() result::ok()
📡

Events

Typed event objects emitted on user creation and post publish. Sync + async via queue.

event::emit() user_created_event
🌐

JSON API

Clean JSON responses for /api/posts and /api/users with pagination meta.

$res->json() /api/posts
🧩

Views + Fragments

Native PHP templates with layout slots. HTMX-aware smart_view() returns fragments on partial requests.

smart_view() @fragment
